Нормальные алгорифмы Маркова

Что такое нормальный алгорифм Маркова?
Понятие нормального алгорифма (алгоритма) было введено советским
математиком А.А. Марковым в конце 1940-х годов как один из способов
формального определения понятия алгоритма, подобно машинам Тьюринга 
и Поста.
 
Нормальный алгоритм задает метод преобразования строк с помощью
системы подстановок. Каждая подстановка состоит из слова-образца 
 и слова-замены, разделенных цепочкой символов «->». На каждом 
шаге замены подстановки просматриваются по порядку сверху вниз,
 и выполняется первая из них, которая подошла: первое найденное
 слово-образец рабочей строки заменяется на слово-замену.

Левая часть (слово-образец) может отсутствовать, в этом случае
 слово-замена ставится в самое начало рабочего слова. Обычно 
такая замена должна стоять последней в списке подстановок 
(иначе происходит зацикливание).
Правая часть подстановки тоже может отсутствовать (при стирании
 образца).
Цепочка символов «->.» означает терминальную подстановку, после
 которой выполнение алгоритма заканчивается. Например:
'а' ->. 'б '  	заменить «а» на «б» и остановить программу
  \* ->. NULL	стереть знак * и остановить программу.
символ NULL специальный в сохранённом текстовом представлении программы
самому в таблице его печатать не нужно, программа сама его формирует.

Столбец комментарий в таблице служит для комментирования программы 
подстановок для облегчения восприятия алгортма Маркова человеком.


Как работать с программой?
В верхней части программы находится  поле редактора, в которое можно
 ввести условие задачи в свободной форме.
Система постановок, задающая нормальный алгорифм Маркова, набирается 
в виде таблицы в нижней части окна программы. 
Программа может выполняться непрерывно (F9) или по шагам (F8). Команда, 
которая сейчас будет выполняться, подсвечивается голубым фоном. 
Скорость выполнения регулируется с помощью меню Скорость.
Задачи можно сохранять в файлах и загружать из файлов. Сохраняется
 условие задачи, исходное слово и система подстановок а также все 
комментарии. 
Протокол работы алгоритма, в котором показаны все последовательные
 замены, вызывается при нажатии меню "Протокол замен". Протокол замен 
может быть сохранён в файл и считан из файла с поторей цвета.
